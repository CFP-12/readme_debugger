🌐 1. GitHub 원격 레포지토리 주소 입력

GitHub 주소를 붙여넣으면 파이썬 기반 프로젝트인지 자동 분석 후 README.md를 검증합니다.

📦 2. 로컬 프로젝트 ZIP 파일 업로드

내 컴퓨터의 프로젝트 폴더를 .zip으로 압축해서 올려주시면 브라우저가 직접 압축을 풀어 분석합니다.
